# irr-design-system (ids) - local AI guidelines

Shared UI kit and design tokens, replacing Angular Material.

Extends `../../AGENTS.md`.

## Standard

Every component follows `STANDARD.md`. Before creating or changing a component, read the sections relevant to the change. Refer to rules as `<category>/<rule>`.

## Facts

- Consumers import entry points: `import { IdsTextInput } from 'irr-design-system/text-input'`.
- Tokens and shared styles: `styles/` (`ids-theme.css`, `_typography.css`, `shared/`).
